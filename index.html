Руководство по проверке

Пошаговая инструкция по использованию программ для анализа системы на наличие запрещённого ПО

13 шагов проверки · By glazki
1 Первичный осмотр ▼
  • Чекнуть Faceit-уровень, Steam-профиль (часы, медали) и историю проверок на cs2bgd31.ru/check/
  • Если ПК-клуб: Попросить игрока доказать, что он в ПК-клубе — записать кружок с окружением. Если скачивать ничего нельзя и меню скрыто — отпустить. Панель задач открывать через Win + D
2 System Informer — Процессы ▼
  • Процесс cs2.exe оранжевый = запущен от администратора — подозрительно
  • ПКМ по steam.exe →Properties →General → Лупа у Command line
    ❌ БАН если в строке есть -sandbox или -applauncher

Память Браузеров
ПКМ по процессу браузера →Properties →Memory →Options →Strings
Значение 6 · все галки включены · режим Filter / regex
Сигнатура (список сайтов читов) — на вкладке «Сигнатуры»
3 Steam → Memory → Strings (скрытый лог) ▼
Открыть steam.exe →Properties →Memory →Options →Strings
Установить значение 5
⚠️ Снять все галки, оставить ТОЛЬКО Image + Mapped
Режим Filter → contains · Сигнатура клиентов — на вкладке «Сигнатуры»
4 Everything — Глубокий поиск файлов ▼
⚠️ Перед началом: проверить Tools→Options→Exclude — список должен быть пуст!
  • Запрос 1 — Поиск по точным размерам файлов
  • Запрос 2 — Поиск по названиям читов / макросов
  • Запрос 3 — Остаточные файлы (token.ms, nl.log и др.)
  • Запрос 4 — Глубокий поиск по UTF8/16 содержимому (18 клиентов)
  • Запросы 5–8 — Обнаружение конкретных клиентов по манифесту

Все запросы с кнопкой копирования — на вкладке «Сигнатуры».
5 USBDeview — История USB-устройств ▼
  • Сортировка по Disconnected Time
  • Если устройство отключено прямо перед проверкой и игрок отказывается вернуть его — ❌ БАН
6 Использование данных — Сеть ▼
  • Проверить трафик приложений на предмет фонового скачивания скрытых лоадеров
  • Обратить внимание на подозрительные процессы с активным исходящим трафиком
7 Last Activity View — Лог действий ▼
  • Сортировка по времени
  • Смотреть, какие файлы и папки открывались прямо перед запуском cs2.exe
8 WinPrefetchView — Кэш запуска ▼
  • Анализ .pf файлов
  • Ищем рандомные названия софта перед проверкой
9 Executed Programs / Cached Programs ▼
  • Поиск удалённого софта, оставшегося в системных логах Windows
  • В утилите Cached Programs нажать на «глаз»
10 Journal Trace — Проверка очистки Prefetch ▼
Drive→Select→ Диск C
Drive→Scan→Layout datagrid
Поиск по .pf

🔎 Критерий бана
Если вы вызвали в 19:00, а логи .pf до 19:00 полностью стёрты (только новые файлы) — это ручная очистка Prefetch.
❌ БАН за сокрытие детектов
11 Previous Files Recovery — Восстановление ▼
  • Сканирование секторов на предмет недавно удалённого ПО
  • Особое внимание на папки Загрузки и Корзина
12 ShellBag Analyzer — Удалённые папки ▼
Нажать Анализ
Фильтр: «Показать все» / «Удалённые папки»
Искать пути к читам, удалённые за последний месяц
13 BrowserDownloadsView — История браузера ▼
  • Анализ загрузок всех браузеров и истории посещений
  • Искать скачивание инжекторов / конфигов
  • Проверить сигнатуру сайтов читов (вкладка «Сигнатуры» → System Informer / Браузеры)
